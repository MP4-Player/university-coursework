# University Coursework

Lab assignments and practice work from the first semester of my bachelor's studies at Don State Technical University (DSTU).
Each subject has its own folder; the original commit history of every assignment is preserved.

## Contents

| Folder | Subject | What's inside |
|---|---|---|
| [`python-fundamentals/`](python-fundamentals) | **Python: Language Fundamentals** | Core Python labs |
| ├ [`labs/`](python-fundamentals/labs) | | File I/O and text processing, OOP with abstract classes (`Vehicle`, `Point`, complex numbers), NumPy array tasks (labs 4–6) |
| ├ [`oop-lab/`](python-fundamentals/oop-lab) | | Class design lab: a record class with instance counting |
| └ [`labs-extended/`](python-fundamentals/labs-extended) | | Extended versions of the same labs, geometric bodies (abstract `Body`), plotting with Matplotlib and SymPy, NumPy exercises (`tasks.ipynb`) |

| [`pascal/`](pascal) | Pascal | Recursive functions counting the number of executor programs (tasks 27–35) |
| [`software-architecture/`](software-architecture) | Software architecture | XML data storage lab: reading, adding and printing records with `xml.etree.ElementTree` |
| [`self-study/`](self-study) | Self-study | Notebook from the Hugging Face NLP course (Transformers pipelines) |
